# 띵과사전

**명조: 워더링 웨이브(Wuthering Waves)의 게임 데이터를 기반으로 스킬, 캐릭터, 파티 시너지, 육성 재료 및 버전별 변경점을 확인할 수 있는 비공식 정보·분석 도구입니다.**

게임 데이터를 버전별로 가져와 로컬 데이터베이스로 구성하며, 단순한 스킬 정보 확인뿐만 아니라 스킬 피해 판정, 공명 체인, 파티 버프, 육성 재료 및 패치 변경점 등을 한곳에서 확인할 수 있도록 제작했습니다.

## 주요 기능

### 🔎 스킬 탐색

캐릭터별 스킬 원문과 상세 정보를 확인할 수 있습니다.

* 일반 공격 / 강공격 / 공중 공격
* 공명 스킬
* 공명 해방
* 변주 / 반주 스킬
* 스킬 레벨별 피해 배율
* 스킬에 사용되는 주요 용어 및 효과 확인
* 공명 체인 정보
* 스킬에서 다른 캐릭터나 효과로 연결되는 항목 탐색

스킬 설명의 특정 용어를 따라가며 관련 정보를 확인할 수 있도록 구성되어 있습니다.

### 🔍 원문 검색

모든 캐릭터의 스킬 및 공명 체인 원문을 검색할 수 있습니다.

특정 효과나 키워드가 들어간 스킬을 빠르게 찾거나, 특정 효과를 가진 캐릭터를 찾아볼 때 사용할 수 있습니다.

### 📊 캐릭터 분석

캐릭터의 스킬이 실제로 어떤 피해 판정으로 분류되는지 확인할 수 있습니다.

* 공명 스킬 / 공명 해방 / 일반 공격 / 강공격 등 피해 유형
* 스킬별 피해 판정
* 반주 버프
* 공명 체인 효과
* 스킬 레벨 투자 우선순위
* 스킬 배율 및 관련 데이터

게임 내 표기만으로 확인하기 어려운 스킬 피해 유형을 데이터 기반으로 정리하는 것을 목적으로 합니다.

### 👥 파티 시너지

최대 3명의 캐릭터를 구성하여 서로의 버프와 공명 체인 효과를 확인할 수 있습니다.

* 캐릭터 3명 구성
* 캐릭터 순서 변경
* 운용 모드 변경
* 공명 체인 단계 변경
* 반주 버프 확인
* 파티 내 캐릭터 간 버프 적용 관계 확인

특정 캐릭터 조합에서 어떤 버프가 서로에게 적용되는지 확인하는 데 사용할 수 있습니다.

### 📖 캐릭터 백과

캐릭터와 관련된 다양한 정보를 한곳에서 확인할 수 있습니다.

* 캐릭터 프로필
* 성우
* 캐릭터 대사
* 스토리
* 소장품
* 생일 정보 및 생일 달력

### 🏆 엔드 콘텐츠

주요 엔드 콘텐츠의 스테이지 및 전투 정보를 확인할 수 있습니다.

* 역경의 탑
* 종말의 매트릭스
* 바닷속 폐허
* 층별 적 정보
* 난이도 및 스테이지 정보
* 스테이지 효과
* 관련 스킬 및 효과

### 📋 육성 재료 계산

캐릭터와 무기의 현재 상태와 목표 상태를 설정하여 필요한 육성 자원을 계산할 수 있습니다.

* 캐릭터 육성 재료
* 무기 육성 재료
* 경험치
* 코인
* 현재 → 목표 레벨
* 여러 캐릭터의 육성 계획을 함께 관리

여러 캐릭터를 동시에 육성할 때 필요한 자원을 한꺼번에 확인할 수 있도록 구성되어 있습니다.

### 🔄 패치 변경점

서로 다른 게임 버전의 데이터를 비교하여 변경된 내용을 확인할 수 있습니다.

* 신규 캐릭터
* 신규 무기
* 변경된 스킬
* 스킬 배율 변경
* 공명 체인 변경
* 세트 및 관련 데이터 변경
* 버전 간 추가 / 변경 / 삭제 데이터

업데이트 후 어떤 데이터가 변경되었는지 빠르게 확인하는 용도로 사용할 수 있습니다.

### 💾 버전별 데이터 관리

게임 데이터를 버전별로 관리할 수 있습니다.

* 사용 가능한 데이터 버전 확인
* 원하는 버전 다운로드
* 로컬 데이터 저장
* 이전 버전과 현재 버전 비교
* 프로그램 실행 시 저장된 데이터 재사용

데이터를 프로그램에 직접 포함하지 않고 필요한 데이터를 원본 저장소에서 가져오는 방식으로 동작합니다.
